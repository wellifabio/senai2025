# Aula08 - VPS02 (Verificação Prática Somativa 02)
- Situação de Aprendizagem Web FullStack
## Projeto (Documentação e Implementação) Válido para Front-end e Back-end
Esta avaliação serve para você se testar, pois trata-se de um projeto Web completo de ponta a ponta. O mínimo que um técnico em Desenvolvimento de sistema deve ser capaz de fazer em um dia de trabalho.

## Instruções
- Faça **fork** do repositório designado na tabela abaixo, clone o projeto que você fez fork no seu computador e siga as instruções em README.md
- Você tem 4 horas para executar todas as tarefas. divirta-se e conte com a ajuda do instrutor, colegas e até IA, porém com sabedoria.
- Desenvolva as documentações utilizando draw.io ou a ferramenta de sua preferência.
- Desenvolva a API utilizando Node.js e Prisma ORM, seguindo as instruções do README.md.
- Desenvolva o front-end utilizando HTML, CSS e JavaScript, seguindo as instruções do README.md.
- Mesmo que não consiga concluir todas as tarefas, faça o máximo que puder e entregue o que foi feito (documentos e telas) mesmo que as funcionalidades não estejam completas.
