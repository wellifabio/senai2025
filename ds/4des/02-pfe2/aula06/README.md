## Como compor um portfolio de programador
- 1 Apresente-se profissionalmente como programador(a) Desktop, WEB, Mobile, Front-End, Back-End, Iot e/ou Full Stack.
- 2 O Portfolio é uma página pública então **não coloque** dados `sensíveis` como
    - Telefone ❌
    - Endereço ❌ (Só a cidade e país no máximo)
    - Foto estilo Instagran ❌ (Dê preferência para uma foto sóbria do rosto apenas ou um avatar)
- 3 Insira links para os seus projetos implantados (deploy com git pages, vercel ou outro)
- 4 Links para os repositórios do Git Hub que possuem algum projeto não implantado mes estudado.
- 5 Responsividade é importante pois hoje o celular é mais utilizado que o computador
- 6 Acessibilidade, crie uma UI (User interface) que seja acessível
    - Ao utilizar imagens preencha os atributos alt e title com a descrição, para leitores de imagem para **cegos**
    - Utilize a semantica correta HTML com (header, main, footer e uma barra nav para links ancorados)
    - Verifique o contraste entre texto e fundo para facilitar para deficiêntes visuais.

## Atividade
Monte uma UI (User interface) **web page** simples contendo links para todos os seus projetos desenvolvidos no curso.
- Pesquise por `portfolio web` na internet para ver exemplos
- Caso deseje use os exemplos dos portfolios dos instrutores
    - [Robson Bachin](https://robsonbsouzaa.github.io/)
    - [Wellington](https://wellifabio.github.io/new/)

### Verificar a Acessibilidade
Todos os tipos de pessoas irão ver seu portfolio por isso a acessibilidade é importante. deve ser fácil para qualquer pessoa navegar pela sua página.
- Assim que publicar no git pages utilize as ferramentas a seguir para testar a acessibilidade do seu portfolio
- **[WAVE](https://wave.webaim.org/)**
- **[USERWAY](https://userway.org/pt/verificador-de-acessibilidade/)**
- **[ASES](https://asesweb.governoeletronico.gov.br/)**
