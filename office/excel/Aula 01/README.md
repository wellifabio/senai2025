# Orçamento do Churrasco

Nessa atividade você irá aplicar os conhecimentos obtidos na aula anterior.

## Passo 1: Copiando os dados

Copie os dados da imagem para uma nova planilha do Excel.

## Passo 2: Formantando os dados

Selecione os dados copiados e aplique a formatação desejada (por exemplo, ajuste de fonte, cor de fundo, bordas, etc.).

## Passo 3: Preenchendo os dados

Preencha os dados restantes na planilha, como o orçamento que você possui para cada item do churrasco.

## Passo 4: Analisando os dados

Analise os dados preenchidos e faça os cálculos necessários para finalizar o orçamento do churrasco.
